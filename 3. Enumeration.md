### Port Scanning With Auxiliary Modules
- **Auxiliary Modules Overview:**
    - Used for various functionalities such as scanning, discovery, and fuzzing.
- **Port Scanning:**
    - Capable of performing both TCP and UDP port scanning.
- **Service Enumeration:**
    - Can enumerate information from services like FTP, SSH, HTTP, etc.
- **Phases of Penetration Testing:**
    - Useful during the information gathering phase of a penetration test.
    - Also applicable in the post-exploitation phase.
- **Network Discovery:**
    - Can discover hosts and perform port scanning on different network subnets.
    - Particularly useful after obtaining initial access to a target system.

### FTP Enumeration
- **Definition**: FTP (File Transfer Protocol) is a protocol that operates over TCP port 21.
- **Purpose**: It facilitates file sharing between a server and one or more clients.
- **Common Use**: Frequently used for transferring files to and from web server directories.
- **Auxiliary Modules**: Multiple auxiliary modules can be utilized for:
    - Enumerating information about FTP servers.
    - Performing brute-force attacks on FTP targets.
- **Authentication**: FTP typically uses a username and password for authentication.
- **Anonymous Access**: Some improperly configured FTP servers may allow anonymous logins.
- 

### SMB Enumeration
- **Definition**:
    
    - SMB (Server Message Block) is a network file sharing protocol.
- **Purpose**:
    
    - Facilitates the sharing of files and peripherals between computers on a local network (LAN).
- **Ports**:
    
    - Uses TCP port 445.
    - Originally ran on top of NetBIOS using port 139.
- **Linux Implementation**:
    
    - SAMBA is the Linux implementation of SMB, enabling Windows systems to access Linux shares and devices.
- **Enumeration Capabilities**:
    
    - Auxiliary modules can be used to:
        - Enumerate the SMB version.
        - List available shares.
        - Identify users.
        - Perform brute-force attacks to discover usernames and passwords.

### Web Server Enumeration
- **Definition**:
    - A web server is software that serves website data over the internet.
- **Communication Protocol**:
    - Web servers use HTTP (Hypertext Transfer Protocol) to facilitate communication between clients and the server.
- **Protocol Details**:
    - HTTP is an application layer protocol that typically operates over TCP port 80.
- **Enumeration Capabilities**:
    - Auxiliary modules can be used to:
        - Enumerate the web server version.
        - Retrieve HTTP headers.
        - Perform brute-force attacks on directories.
        - Conduct various other assessments.
- **Popular Web Servers**:
    - Examples include:
        - Apache
        - Nginx
        - Microsoft IIS

### SSH Enumeration
- **Definition**:
    - SSH (Secure Shell) is a remote administration protocol that provides secure encrypted communication.
- **Successor to**:
    - SSH is the successor to Telnet, which does not offer encryption.
- **Common Uses**:
    - Typically used for remote access to servers and systems.
- **Default Port**:
    - SSH uses TCP port 22 by default.
    - It can be configured to use any other open TCP port.
- **Enumeration and Functionality**:
    - Auxiliary modules can be utilized to:
        - Enumerate the version of SSH running on the target.
        - Perform brute-force attacks to identify passwords.
